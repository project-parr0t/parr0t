Parr0t

프롬프트 조합기

생성된 실행 명령을 PowerShell에 붙여 넣으세요. 현재 공식 Core 체크아웃과 OMP가 필요합니다. 명령은 명시적 전체 부트스트랩에서 parr0t_session을 먼저 호출한 뒤 요청에 따라 공식 컨트롤러를 시작합니다. 전역 확장 등록·설치는 하지 않으며, 역할별 모델 선택은 이 실행의 --config에만 적용해 전역 기본값을 유지합니다. 생성만으로 실행되거나 모델 권한이 확인되지는 않습니다. 브라우저는 게임 파일을 읽지 않으며 명령 생성에는 네트워크 조회가 없습니다. localhost 모델 목록 조회는 별도 선택입니다.

모델·문맥
검수 명시한 상한 우선 · 최초 호출 포함

켜면 OpenCodex 모델 목록을 읽기 위해 http://localhost:10100에 연결합니다. 필요한 경우 브라우저의 로컬 네트워크 접근 권한을 허용하세요. 이미 차단했다면 사이트 설정에서 변경하세요. 이 권한은 CORS를 해제하지 않으며, 서버가 현재 사이트의 origin을 허용하지 않으면 모델 목록을 읽을 수 없습니다.
